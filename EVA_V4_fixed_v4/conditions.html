2. DESCRIPTION DU SERVICE

E.V.A est un assistant virtuel intelligent propulsé par l'intelligence artificielle, développé par Astral Technologie. La version Beta V4 comprend notamment :

  • Conversations intelligentes via plusieurs fournisseurs d'IA (Puter AI, OpenAI GPT-4o, Claude Anthropic, Qwen 3, LM Studio, Ollama)

  • Gestion de notes, alarmes, rappels et agenda intégrés
  • Génération de fichiers : PDF, PPTX, DOCX, XLSX directement depuis le chat
  • Module CloudWorks pour la gestion de tâches et projets
  • Rapports et statistiques d'utilisation (accès selon rôle utilisateur)
  • Système de clés développeur permettant l'attribution de rôles spéciaux (Créateur, Épouse du Créateur, Développeur)
  • Recherche web intégrée depuis l'interface de chat
  • Analyse et interprétation d'images (vision IA)
  • Orbe holographique 3D interactif basé sur Three.js / VRM
  • Mode expérimental avec fonctionnalités avancées en preview
  • Tutoriel interactif d'onboarding
  • Interface progressive web app (PWA) installable sur tous les appareils
